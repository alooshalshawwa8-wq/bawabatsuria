# بوابة سورية الوطنية الماسية الشاملة

واجهة عربية RTL لخدمات ومعلومات موجهة للمستخدم السوري.

## حالة التطوير

يجري العمل على فرع `stabilize-portal`، مع إبقاء `main` دون تعديل حتى مراجعة التغييرات.

### ما تم إصلاحه في هذه الجولة
- إصلاح بنية بطاقات الخدمات المقطوعة وإعادة حاوياتها.
- إصلاح اختيار تبويبات المحاور دون الاعتماد على متغير الحدث العام.
- عرض ردود المساعد كنص آمن بدلاً من تفسيرها كـ HTML.
- إضافة ملف Manifest ثابت وأيقونة SVG صالحة للتطبيق.
- تحسين دورة حياة Service Worker والتخزين المؤقت والعمل دون اتصال.
- منع تفاعل زر VIP الداخلي من تشغيل نقرة بطاقة الخدمة الخارجية.

## تشغيل محلي

يمكن تقديم الملفات عبر أي خادم ملفات ثابت يدعم HTTPS في النشر:

```bash
python -m http.server 8000
```

ثم افتح `http://localhost:8000`.

## ما لم يصبح جاهزاً بعد

- المساعد الشامي الحالي يعتمد على قواعد محلية، وليس اتصال Gemini حقيقياً.
- لا يوجد backend آمن منشور لاستدعاء Gemini. لا تضع مفتاح `GEMINI_API_KEY` في ملفات الواجهة أو المستودع العام.
- عضوية VIP والنقاط الحالية مخزنة في المتصفح، لذلك ليست نظام دفع أو اشتراك آمناً ولا يجوز استخدامها لمنح مزايا مدفوعة حقيقية.
- بطاقات الخدمات هي حالياً دليل واجهة؛ يلزم بناء صفحات/مصادر فعلية لكل خدمة بدلاً من رسائل التنبيه.
- لم يتم تأكيد مزود الاستضافة أو عنوان الموقع المنشور بعد.

## متطلبات الإطلاق الحقيقي

1. اختيار استضافة تدعم HTTPS ووظائف خادم (مثل Vercel أو بديل مناسب).
2. إضافة `GEMINI_API_KEY` كمتغير بيئة سري في إعدادات الخادم فقط.
3. بناء API خلفي مع تحديد معدل الطلبات والتحقق من المدخلات.
4. اعتماد مزود دفع/اشتراك موثوق والتحقق من المدفوعات على الخادم.
5. اختبار الواجهة على متصفحات وأجهزة فعلية قبل إعلان الإطلاق.

لا تُدخل أي مفاتيح API أو كلمات مرور أو بيانات دفع في هذا المستودع.
