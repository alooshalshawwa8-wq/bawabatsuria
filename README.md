# بوابة سورية الوطنية الماسية الشاملة

واجهة عربية RTL لخدمات ومعلومات موجهة للمستخدم السوري.

## حالة التطوير

يجري العمل على فرع `stabilize-portal`، مع إبقاء `main` دون تعديل حتى مراجعة التغييرات.

### ما تم إصلاحه في هذه الجولة
- إصلاح بنية بطاقات الخدمات المقطوعة وإعادة حاوياتها.
- إصلاح اختيار تبويبات المحاور دون الاعتماد على متغير الحدث العام.
- عرض ردود المساعد كنص آمن بدلاً من تفسيرها كـ HTML.
- إضافة ملف Manifest ثابت وأيقونة SVG صالحة للتطبيق.
- تحسين دورة حياة Service Worker والتخزين المؤقت والعمل دون اتصال.
- منع تفاعل زر VIP الداخلي من تشغيل نقرة بطاقة الخدمة الخارجية.

## تشغيل محلي

يمكن تقديم الملفات عبر أي خادم ملفات ثابت يدعم HTTPS في النشر:

```bash
python -m http.server 8000
```

ثم افتح `http://localhost:8000`.

## ما لم يصبح جاهزاً بعد

- واجهة المساعد تستدعي `/api/chat`، لكن اتصال Gemini لم يُنشر أو يُختبر بمفتاح فعلي بعد. أضف `GEMINI_API_KEY` في إعدادات المشروع السرية على Vercel فقط؛ لا تضعه في ملفات الواجهة أو المستودع العام. عند فشل الاتصال تظهر استجابة محلية محدودة بوضوح.
- لا توجد حالياً نقاط أو مكافآت قابلة للاستبدال، ولا نظام حسابات أو عضوية VIP فعّال. أزيلت مكافآت المتصفح الوهمية حتى لا توحي بوجود رصيد أو استحقاق حقيقي.
- بطاقات الخدمات هي حالياً دليل واجهة؛ يلزم بناء صفحات ومصادر فعلية لكل خدمة. قسم الأمان يقدم إرشادات توعوية فقط ولا يفحص الروابط تقنياً.
- لم يتم تأكيد مزود الاستضافة أو عنوان الموقع المنشور بعد.

## متطلبات الإطلاق الحقيقي

1. اختيار استضافة تدعم HTTPS ووظائف خادم (مثل Vercel أو بديل مناسب).
2. إضافة `GEMINI_API_KEY` كمتغير بيئة سري في إعدادات الخادم فقط.
3. بناء API خلفي مع تحديد معدل الطلبات والتحقق من المدخلات.
4. اعتماد مزود دفع/اشتراك موثوق والتحقق من المدفوعات على الخادم.
5. اختبار الواجهة على متصفحات وأجهزة فعلية قبل إعلان الإطلاق.

لا تُدخل أي مفاتيح API أو كلمات مرور أو بيانات دفع في هذا المستودع.


## عالم كرة القدم

- تمت إضافة واجهة عالم كرة القدم إلى فرع `stabilize-portal` عبر `football.js` و`football.css`، وتُحمّل البيانات من Supabase Edge Function `football-data` فقط؛ لا يُرسل مفتاح API-Football السري إلى المتصفح.
- تشمل الواجهة المباريات، البطولات، الترتيب، الهدافين والصناعة والبطاقات، الأندية والملاعب، اللاعبين وكشاف المواهب، مركز المباراة، التوقعات، الخطط، DNA الأندية، اللحظات، جواز المشجع المحلي، الأكاديمية والديربيات.
- التحديث يدوي وعند الطلب، مع التخزين المؤقت وحماية الميزانية. لا توجد عملية تحديث تلقائي مستمر تستهلك الحصة.
- حساب API-Football كان معلّقاً عند آخر تحقق؛ تم تفعيل قاطع حماية في الخلفية، لذلك لا تُرسل طلبات بيانات جديدة حتى يؤكد المزود عودة الحساب. يلزم اختبار البيانات الحية بعد إعادة التفعيل.
